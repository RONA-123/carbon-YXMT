# 应县木塔互动展示

纯静态 Three.js 网页，包含全塔交互、斗栱研究室、造像近观及资料说明。无需安装依赖或构建。

## 上传并发布

1. 在 GitHub 创建仓库（使用免费 GitHub Pages 时，可选择 Public 公开仓库）。
2. 解压本包，进入文件夹，把里面的全部文件和目录上传到仓库根目录。根目录应直接包含 `index.html`，不要多套一层文件夹。不要把ZIP本身当成网站上传。
3. 进入仓库 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. Branch 选择 **main**，目录选择 **/(root)**，点击 **Save**。
6. 等待部署完成，页面会显示网站地址，通常为 `https://你的用户名.github.io/仓库名/`。

请完整保留 media、vendor、utils 等目录；模型与解码文件缺失会导致网页无法显示。

## 模型版本与资料边界

全塔使用第四版整合模型，包含26尊解释性造像。第五、第六版主佛为独立研究样板，尚未替换全塔，因此本网站不冒称已采用第六版全塔造像。

本模型是解释性展示，不是文物扫描或修缮测绘模型。部分尺寸、布局、榫卯、造像细节及配色含推定，详见页面内说明。

## 图片与公开发布

原页面使用的用户参考图，原作者及公开转载授权尚未确认。本公开上传包已移除这些原始参考图，并保留说明与研究来源链接；自行补充图片时请核实署名和许可。

vendor 中第三方库保留其原有许可文件。GitHub Pages 为公开网站，上传的模型与其他静态文件可被访问和下载。
